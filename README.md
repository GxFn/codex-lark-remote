# Codex Lark Remote

This repository is a Codex plugin marketplace for `codex-lark-remote`.

The real plugin bundle lives only under
[`plugins/codex-lark-remote/`](plugins/codex-lark-remote/). For installation,
configuration, and usage docs, read the bundled plugin README:

- [English plugin docs](plugins/codex-lark-remote/README.md)
- [中文插件文档](plugins/codex-lark-remote/README.zh-CN.md)

The repository root only keeps marketplace entrypoint files, tests, and
development metadata. It should not contain a duplicate copy of the plugin
implementation.
